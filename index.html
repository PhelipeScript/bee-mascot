Integrações no sistema

Tudo que o mascote faz em uma página real — ao vivo nesta demo.

1 · Favicon dinâmico

estado: idle

Troque de estado e observe o ícone da aba (e a prévia) mudarem.

Rasterização: frame SVG → blob → canvas 64px → PNG, cacheada por chave e com throttle de ~7 trocas/s.

2 · Loader global & local

área do loader local

Cada loader cria a própria instância da abelha dentro do overlay (o rAF é compartilhado entre instâncias).

3 · Reações de feedback

Reações somam força à FSM (fuga/tremor) sem trocar o estado atual — momentum sempre preservado.

4 · Modo companheiro (dock)

convide a abelha para ficar aqui

bee.dock(el) ancora a órbita no elemento; bee.undock() devolve o voo livre.

5 · Guia de onboarding

4 passos: a abelha voa até cada elemento enquanto um ring de destaque e o card acompanham.

ESC encerra · funciona em DOM dinâmico (alvos por seletor).

6 · Acessibilidade & performance

prefers-reduced-motion: verificando…

A física pausa sozinha quando o container sai da viewport ou a aba fica oculta (IntersectionObserver + visibilitychange).

7 · Chamar equipe (callHelp)

A abelha-chefe chama 3–5 auxiliares, cada um com um papel — e auto-retorna ao estado anterior quando a tarefa termina.

  • batedora órbita ampla mapeando a tarefa
  • construtora leva pólen do depósito ao alvo
  • sentinela patrulha o perímetro
  • mensageira corre entre a chefe e a tarefa
  • analisadora radar par acima do alvo
0 auxiliares

Nº de auxiliares segue a qualidade: low 3 · medium 4 · high 5 (ou helpers explícito na chamada).

API em 10 linhas

Instalação no sistema real: npm i + 1 import + 1 chamada.

import { createBeeMascot, createFavicon, attachReactions }
  from '@sistema/bee-mascot';

const bee = createBeeMascot({
  container: document.querySelector('#camada-flutuante'),
  initialState: 'idle',
  quality: 'high',
});

bee.setState('followTarget', { target: 'mouse' });
bee.setTarget(document.querySelector('#botao-onboarding'));
bee.celebrate();            // auto-retorna ao estado anterior
bee.setLoading(0.6);        // 0..1 vira anel de progresso
bee.dock(document.querySelector('#sidebar'));
bee.callHelp({ target: '#tarefa' }); // chama 3–5 auxiliares

createFavicon(bee);                     // ícone da aba vivo
attachReactions(bee);                   // [data-bee] + forms
